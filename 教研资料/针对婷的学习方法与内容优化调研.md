# 针对婷的学习方法与内容优化调研

> 调研日期：2026-05-10  
> 目标：把网上可查的学习科学、动机研究、课程内容要求，转成适合婷的可执行教学策略。  
> 使用方式：详细依据看本文件；日常带课先读 `教学策略.md` 和对应周计划。

---

## 中间发现

1. 学习科学里证据最稳的一组方法是：主动回忆、间隔复习、穿插练习、样例学习、自我解释、具体例子/双编码。
2. 这些方法和婷的情况高度匹配：他抽象讲解容易掉线，但具体画面、类比、短任务、变式确认更可能有效。
3. 动机研究强调自主感、胜任感、关系感。对婷这种内驱明显、抗催促的学生，硬压通常不如“给选择 + 小成功 + 像学长一样陪着走”。
4. 高一内容仍要围绕必修范围，不能被“技巧”带偏：英语抓词汇和句子，数学抓函数/三角/向量，语文抓文言文和阅读表达。

---

## 证据转教学动作

| 研究结论 | 适合婷的做法 | 不建议 |
|----------|--------------|--------|
| 主动回忆比反复看更能稳固记忆 | 旧词/旧题先小测，再讲 | 开头直接复述答案 |
| 间隔复习比集中突击更稳 | 1/2/4/7/15 天复现错词错题 | 今天会了就不再管 |
| 穿插练习能提升迁移 | 同一题型练 1-2 题后放一个小变式 | 连刷 10 道一模一样的题 |
| 样例学习能降低新手负担 | 先给一题完整示范，再让他仿做 | 一上来让他独立硬做 |
| 自我解释能暴露假懂 | 让他说“为什么第一步这么做” | 只问“懂了吗” |
| 具体例子和图像能帮助抽象理解 | 用钓鱼、学校、生活场景解释 | 直接堆概念和术语 |
| 自主感会增强动机 | 给二选一，让他参与决定 | 只用命令式安排 |

## 针对婷的学习画像再解释

### 1. 启动困难

不是简单懒。更像是任务一大，大脑先抗拒。所以教学要把任务切小：

```text
只回 A/B
只做第一步
只翻译一句
只看这个词
```

### 2. 具象型理解

他需要“脑子里有画面”。英语词汇要有场景，数学公式要有形状或题型标签，语文主旨要能讲成故事。

### 3. 会听不会做

这类学生常见表现是听讲时点头，换一题就不会。解决办法不是再讲一遍，而是：

```text
例题 → 同型题 → 小变式 → 让他说第一步
```

### 4. 内驱明显

他觉得有意思时会动，不感兴趣时外部压力效果差。教学要保留一点“像聊天一样”的入口，尤其可以借钓鱼切入。

## 三科内容优化

### 英语

现状：基础弱，能认简单词但连不懂句子；5/8 主动提出要学，是重要窗口。

优化方向：

1. 高频词继续推进，但每天 10 个里要分层：7 个核心词 + 3 个挑战词。
2. 每个词必须进入句子，句子必须能拆主干。
3. 错词第二天不重讲，先主动回忆。
4. 每周日不新增大量词，做总复盘和错词清理。
5. 新词尽量选高一主题可复用词：校园、成长、方法、自然、文化、科技、社会。

英语每晚结构：

```text
3 分钟：旧词主动回忆
10 分钟：新词画面联想
8 分钟：3 个句子拆主干
7 分钟：5-8 道小测
2 分钟：记录错词
```

### 数学

现状：三角函数、向量讲过不少；最大短板是辅助角公式；常见问题是知道概念但不知道第一步。

优化方向：

1. 每题先贴题型标签，不直接算。
2. 每次只攻一类启动动作，例如“a sin x + b cos x 先算 R”。
3. 讲题要用 worked example 降低负担。
4. 用变式题检验迁移：换符号、加常数、问最小值。
5. 向量复习要围绕投影长度、投影向量、夹角、垂直这些易混点。

数学每节结构：

```text
题型标签 → 第一眼看什么 → 例题完整走一遍 → 同型题让他做 → 变式题验真懂
```

### 语文

现状：文言文全面薄弱；《庖丁解牛》待讲；作文有明确格式偏好。

优化方向：

1. 文言文先讲故事和主旨，再讲字词句。
2. 每课最多抓 5 个高频文言点，避免术语轰炸。
3. 阅读题先让他复述“这篇说了什么”，再讲答题模板。
4. 作文训练只练一个动作：观点、分论点、例子分析、结尾。
5. 把文言主旨和现实类比，比如《庖丁解牛》对应“看懂结构，不蛮干”。

语文每节结构：

```text
故事/画面 → 婷复述一句 → 核心句翻译 → 3-5 个考点 → 1 道主旨题或小表达
```

## 学习内容补充路线

### 英语内容池

后续选词优先来自这些主题：

| 主题 | 词汇方向 |
|------|----------|
| 学习方法 | approach, method, focus, improve, practice, review |
| 成长与心理 | challenge, confidence, effort, responsible, attitude |
| 校园生活 | experience, activity, prepare, support, relationship |
| 自然与环境 | environment, protect, reduce, condition, influence |
| 社会与文化 | culture, tradition, common, include, compare |
| 科技与生活 | technology, information, develop, provide, create |

### 数学内容池

后续优先顺序：

1. 辅助角公式：最大值、最小值、加常数、换符号。
2. 三角函数图象：周期、单调、对称轴、零点。
3. 向量：数量积、夹角、投影、垂直、最值。
4. 函数：定义域、值域、单调性、零点。
5. 概率统计：用生活例子做轻量补充。

### 语文内容池

后续优先顺序：

1. 《庖丁解牛》：故事、主旨、核心句、通假/古今异义。
2. 文言文通用能力：实词猜义、句子主干、人物关系。
3. 现代文阅读：概括内容、分析情感、找依据。
4. 作文：中心观点、分论点、例子分析、短结尾。
5. 成语/诗词轻推：用于低压力启动。

## 后续教学有效性检查

每周日只看 5 个指标：

1. 英语：本周 50 个词里，能稳定认出几个？
2. 英语：能否独立拆 1 个简单句主干？
3. 数学：遇到本周题型，能否说出第一步？
4. 语文：能否用自己的话说出文章主旨？
5. 状态：本周哪种开场最容易让他回复？

如果指标没达成，不是加量，而是降任务颗粒度。
