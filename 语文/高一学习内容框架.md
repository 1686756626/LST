# 高一语文学习内容框架

> 用途：AI 上语文课前快速读取。  
> 当前学生：婷，文言文薄弱，《庖丁解牛》待讲。

---

## 高一范围

优先范围：普通高中语文必修上册、必修下册。

核心不是背篇目，而是训练四件事：

1. 读懂现代文：人物、事件、观点、情感。
2. 读懂文言文：字词、句子、人物关系、观点。
3. 读懂古诗词：画面、情绪、手法。
4. 写清楚作文：观点、例子、分析、结尾。

---

## 给婷的语文打法

| 场景 | 做法 |
|------|------|
| 文言文不会 | 先讲故事，再逐句翻译，最后拎考点 |
| 现代文不会 | 先问“这篇到底说了什么”，再看题 |
| 古诗词不会 | 先让他说画面和情绪，再补术语 |
| 作文写不动 | 先给结构：观点-例子-分析 |
| 不想学 | 发一道很短的题，降低启动门槛 |

## 《庖丁解牛》建议讲法

第一步只讲故事：

庖丁给梁惠王解牛，动作特别顺，像表演。梁惠王惊了，问他怎么做到的。庖丁说：我刚开始看到的是整头牛，后来看到的是骨节和空隙，现在靠感觉顺着结构走，不硬砍。

第二步抓主旨：

不是讲杀牛技术，而是讲“做事要顺着规律走”。熟练不是死练，是理解结构之后越做越顺。

第三步再拆考点：

| 考点 | 讲法 |
|------|------|
| 实词 | 结合句子翻译，不孤立背 |
| 虚词 | 只抓本课高频用法 |
| 句式 | 遇到再讲，别提前堆 |
| 主旨 | “依乎天理”“因其固然”都指顺规律 |

第四步出变式题：

让婷用自己的话解释：为什么庖丁不是靠蛮力？

## 作文适配

婷的作文偏好：

- 分论点单独成段加粗。
- 中心主旨放第一段末尾。
- 最后一段不要太长。
- 不要英文字母。

AI 写作训练不要代写整篇，优先练：

1. 审题后写一句中心观点。
2. 把一个分论点写清楚。
3. 给一个例子补两句分析。
4. 把结尾压短、压稳。
