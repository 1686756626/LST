## 周二 5/12：《庖丁解牛》第一课

### 课前目标

婷能说出：

```text
庖丁不是靠蛮力，是看懂了牛的结构，顺着规律做事。
```

### 开场话术

```text
婷，今天《庖丁解牛》先不背。
你就把它当一个“高手为什么像开挂”的故事听。
```

### 故事版讲解

```text
庖丁给梁惠王解牛，动作特别顺，像在表演。
梁惠王看懵了：你这技术怎么这么强？
庖丁说，我追求的不是技术，是道。
刚开始我看到的是整头牛，后来我看到的是骨头、筋络和空隙。
现在我顺着牛本来的结构走，不硬砍，所以刀用了很多年还像新的。
```

### 主旨

```text
这篇不是教人怎么切牛。
它讲的是：真正厉害的人，不是靠蛮力，而是看懂规律，顺着结构做事。
```

可以顺手类比：

```text
钓鱼也是这样。
乱抛是蛮力，看水流、看风、看鱼口，再选饵和标点，这才是顺规律。
```

### 核心句 1

原句：

```text
臣之所好者道也，进乎技矣。
```

拆法：

```text
臣：我
之：放在主谓之间，先不用细讲
所好者：喜欢/追求的东西
道：规律、道理
进乎技：超过技术
```

翻译：

```text
我所追求的是规律，已经超过一般技术了。
```

问婷：

```text
这句话里，庖丁说自己厉害在哪？是手快，还是懂规律？
```

答案方向：懂规律。

### 核心句 2

原句：

```text
依乎天理，批大郤，导大窾，因其固然。
```

拆法：

```text
依乎天理：顺着牛天然的纹理
批大郤：击入大的缝隙
导大窾：顺着大的空处走
因其固然：顺着它本来的样子
```

翻译：

```text
顺着牛天然的结构，进入大的缝隙，沿着大的空处走，顺着它本来的样子。
```

### 小练习

1. 《庖丁解牛》表面写什么？实际讲什么？
2. “臣之所好者道也，进乎技矣”中，“道”可以理解成什么？
3. 庖丁为什么刀用了很多年还像新的？

### 答案

1. 表面写解牛，实际讲顺应规律做事。
2. 规律、道理。
3. 因为他顺着牛的结构走，不硬砍硬碰。

## 周四 5/14：《庖丁解牛》第二课

### 课前目标

把主旨落到文言考点和表达训练。

### 开场话术

```text
上次我们说庖丁不是蛮干，是看懂结构。
今天把里面几句考试爱问的话拿一下，不多，就几句。
```

### 核心句 3

原句：

```text
以无厚入有间，恢恢乎其于游刃必有余地矣。
```

拆法：

```text
无厚：没有厚度，指刀刃很薄
有间：有空隙
游刃：刀刃运转
余地：有空间
```

翻译：

```text
用很薄的刀刃进入有空隙的地方，刀刃活动起来一定还有很大余地。
```

讲法：

```text
这句就是“顺着空隙走，所以不费劲”。
学习也一样，找到结构和入口，比硬撞舒服。
```

### 核心句 4

原句：

```text
善刀而藏之。
```

拆法：

```text
善：通“缮”，擦拭、修治
刀：刀
而：然后
藏之：把它收藏起来
```

翻译：

```text
把刀擦拭好，然后收藏起来。
```

提醒：

```text
这里的“善”不是善良，是通假字，考试可能问。
```

### 文言考点小表

| 词句 | 考点 | 解释 |
|------|------|------|
| 道 | 实词 | 规律、道理 |
| 技 | 实词 | 技术 |
| 天理 | 古今异义 | 天然结构、自然纹理 |
| 固然 | 古今异义 | 本来的样子 |
| 善刀 | 通假 | 善，通“缮”，擦拭 |
| 游刃有余 | 成语 | 做事熟练，解决问题轻松 |

### 主旨题

题目：

```text
《庖丁解牛》想告诉我们什么道理？请用自己的话回答。
```

参考答案：

```text
做事不能只靠蛮力，要先看懂对象本身的结构和规律，顺着规律去做，才能熟练、轻松、有效。
```

### 小作文训练

题目：

```text
用“顺着规律做事”为中心，写一段 120 字左右的小议论。
```

给婷的结构：

```text
第一句：观点。
第二句：解释。
第三句：举例。
第四句：分析。
第五句：收住。
```

示例：

```text
做事要先看懂规律，而不是一味硬来。规律就像一条路，找到了路，行动才不会乱。庖丁解牛时不是靠力气乱砍，而是顺着牛本来的结构下刀，所以才能游刃有余。学习也是这样，先看懂题型和文章结构，再动手做，效率会高很多。懂规律，比蛮用力更重要。
```

### 练习

1. “善刀而藏之”里的“善”是什么意思？
2. “因其固然”里的“固然”是什么意思？
3. “游刃有余”现在常用来形容什么？
4. 写一句话：学习里什么叫“顺着规律做事”？

### 答案

1. 通“缮”，擦拭、修治。
2. 本来的样子。
3. 做事熟练、轻松、有余地。
4. 示例：先看懂题型和方法，再做题，而不是乱算。
