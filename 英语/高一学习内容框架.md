# 高一英语学习内容框架

> 用途：AI 上英语课前快速读取。  
> 当前学生：婷，英语基础很弱，但 5/8 主动提出要学；中等难度词最合适。

---

## 高一范围

优先范围：普通高中英语必修第一册、必修第二册、必修第三册。

若学校使用人教版新教材，常见主题大致包括：

| 册次 | 常见主题 |
|------|----------|
| 必修第一册 | 青少年生活、旅行、运动健康、自然灾害、语言文化 |
| 必修第二册 | 文化遗产、野生动物保护、互联网、历史传统、音乐 |
| 必修第三册 | 节日文化、道德选择、多元文化、太空探索、金钱价值 |

具体单元名称以婷学校教材目录为准。

## 当前英语策略

每天晚上统一推：

1. 10 个高考高频词。
2. 3 个句子。
3. 5-8 道练习题。
4. 到期旧词复习。

每个词必须有：

| 项目 | 要求 |
|------|------|
| 英文 | 单词原形 |
| 谐音 | 中文谐音，方便启动 |
| 中文 | 简洁解释 |
| 画面 | 钓鱼/学校/生活场景 |
| 例句 | 不要太难，能读懂结构 |
| 小练习 | 选择、填空、英译中都行 |

## 艾宾浩斯复习规则

复习间隔：1 天、2 天、4 天、7 天、15 天。

5/8 第一批词：

| 单词 | 状态 | 画面 |
|------|------|------|
| interpret | 未掌握 | 学长帮你解释英文 |
| potential | 已掌握 | 新鱼竿有潜力钓大翘嘴 |
| perspective | 未掌握 | 站不同位置看赣江 |
| consume | 未掌握 | 钓一天鱼吃一大碗粉 |
| impact | 已掌握 | 暴雨影响鱼口 |

5/10 应做第二天复习：interpret / potential / perspective / consume / impact。

## 句子拆解法

婷能认一些词，但容易连不成句。不要先讲复杂语法术语，先用四问：

1. 谁？
2. 干什么？
3. 对谁/什么？
4. 补充说明是什么？

例子：

```text
The heavy rain had a big impact on fishing.
```

拆：

```text
谁：The heavy rain，大雨
干什么：had，有
对什么：a big impact，很大影响
补充：on fishing，对钓鱼
整句：大雨对钓鱼有很大影响。
```

## 难度控制

| 难度 | 例子 | 婷的反应 | 使用建议 |
|------|------|----------|----------|
| 太简单 | because | 可能觉得弱智 | 少用作新词 |
| 合适 | interpret / potential / impact | 有挑战但能学 | 主力难度 |
| 太难 | comprehensive | 容易掉线 | 暂时少放 |

## 下次推送可用结构

```text
婷，今晚先不搞多，复习 5 个旧词。

1. interpret 印-特-普-瑞-特：解释
画面：英文看不懂，我给你解释一遍。

句子：
Can you interpret this sentence?
你能解释这个句子吗？

小题：
interpret 的意思是：
A. 解释
B. 消耗
C. 影响
```

注意语气像学长，别像教辅书。
