# 高一数学学习内容框架

> 用途：AI 上数学课前快速读取。  
> 当前学生：婷，三角函数和向量讲过很多，辅助角公式是最大短板；物理/数学都需要“先讲思路再算”。

---

## 高一范围

优先范围：普通高中数学必修第一册、必修第二册。

不同学校教材版本和章节顺序可能不同，但高一主线基本围绕：

| 主线 | 内容 |
|------|------|
| 初高中衔接 | 集合、逻辑、不等式、二次函数基础 |
| 函数 | 函数概念、性质、图象、幂/指数/对数函数、函数应用 |
| 三角函数 | 任意角、诱导公式、图象性质、恒等变换、辅助角 |
| 平面向量 | 向量运算、数量积、投影、夹角、垂直、最值 |
| 几何与代数 | 复数、立体几何初步 |
| 概率统计 | 随机事件、概率、数据统计 |

## AI 讲题流程

每道题都按这个顺序：

1. 这题给了什么？
2. 这题要你求什么？
3. 它像哪一类题？
4. 第一步能做什么？
5. 算完以后用变式题确认。

不要一上来给完整答案。

## 辅助角公式最小教学块

只先处理一种形态：

```text
a sin x + b cos x
```

讲法：

1. 先说目的：把两个三角函数合成一个，方便看最大值最小值。
2. 再说结果：它可以变成 R sin(x + φ) 或 R cos(x - φ)。
3. 先不纠结 φ 的名字，先算 R。
4. R = sqrt(a^2 + b^2)。
5. 让婷做一个数字小题，比如 3sinx + 4cosx。

确认题：

```text
3sinx + 4cosx 的最大值是多少？
```

只要他说出最大值是 5，就先算过关，再补角度细节。

## 向量复习标签

| 题型 | 启动句 |
|------|--------|
| 模长 | 先平方，转成数量积 |
| 夹角 | 想 cosθ = a·b / |a||b| |
| 垂直 | 想数量积等于 0 |
| 投影长度 | 想 |a|cosθ 或 a·b / |b| |
| 投影向量 | 有方向，是一个向量，不是单纯长度 |
| 最值 | 看能不能转成二次函数、均值、乘1法 |
