## 周一 5/11：辅助角入门

### 课前目标

让婷记住一句话：

```text
看到 a sin x + b cos x，先算 R = sqrt(a^2 + b^2)。
```

### 开场话术

```text
婷，今天数学就一个点。
3sinx + 4cosx 最大值是多少？你别急着算角，先看 3 和 4。
```

### 讲解脚本

题目：

```text
求 3sinx + 4cosx 的最大值。
```

第一步问：

```text
这题长得像什么？
它是 a sin x + b cos x。
```

第二步：

```text
a = 3，b = 4。
R = sqrt(3^2 + 4^2) = 5。
```

第三步：

```text
所以 3sinx + 4cosx 最大值是 5，最小值是 -5。
先别管它具体在哪个 x 取到，今天先把“最大幅度是 5”吃下来。
```

### 确认题

```text
求 5sinx + 12cosx 的最大值。
```

引导：

```text
a = 5，b = 12。
R = sqrt(5^2 + 12^2) = 13。
最大值 13。
```

### 变式题

1. `8sinx + 15cosx` 的最大值是多少？
2. `7sinx - 24cosx` 的最大值是多少？
3. `-6sinx + 8cosx` 的最大值是多少？

答案：

1. 17
2. 25
3. 10

### 课后记录

只记录一个判断：婷能不能自己说出 `R = sqrt(a^2 + b^2)`。

## 周三 5/13：辅助角变式 + 向量投影

### 课前目标

把“最大值是 R”迁移到有常数项的题。

### 开场话术

```text
上次 3 和 4 合成 5。
今天只加一点点：后面多一个常数，不慌，先把前面合成。
```

### 讲解题 1

题目：

```text
求 3sinx + 4cosx + 2 的最大值。
```

步骤：

```text
先看 3sinx + 4cosx，最大是 5。
后面 +2 跟着一起加。
所以最大值 = 5 + 2 = 7。
```

确认题：

```text
求 5sinx - 12cosx - 3 的最大值。
```

答案：

```text
前面最大是 13。
13 - 3 = 10。
```

### 讲解题 2：向量投影复习

题目：

```text
已知 |a| = 4，|b| = 5，a 与 b 的夹角为 60°。
求 a 在 b 方向上的投影长度。
```

讲法：

```text
投影长度就是把 a 往 b 的方向照过去。
公式：|a|cosθ。
所以是 4cos60° = 2。
```

提醒：

```text
投影长度是一个数。
投影向量才是一个有方向的向量。
这两个别混。
```

### 变式题

1. `4sinx + 3cosx + 1` 的最大值是多少？
2. `12sinx - 5cosx + 6` 的最大值是多少？
3. 已知 `|a|=6`，a 与 b 夹角 60°，a 在 b 方向上的投影长度是多少？

答案：

1. 6
2. 19
3. 3

## 周五 5/15：薄弱项机动

默认优先补数学；如果婷明显不想算，就切语文。

### 方案 A：继续数学

目标：确认辅助角不是只会一题。

快问快答：

1. `6sinx + 8cosx` 最大值？
2. `9sinx - 12cosx` 最大值？
3. `3sinx + 4cosx - 5` 最大值？
4. `8sinx + 15cosx + 2` 最小值？

答案：

1. 10
2. 15
3. 0
4. -15

第 4 题解释：

```text
8sinx + 15cosx 的范围是 [-17, 17]。
再 +2，范围是 [-15, 19]。
所以最小值是 -15。
```

### 方案 B：如果婷烦数学，切语文

发这个：

```text
庖丁厉害不是因为力气大，是因为他看懂了牛的结构。
你觉得学习里有没有类似的事：不是硬背，而是看懂结构？
```

只要他回一句，就顺着聊，不硬推题。
